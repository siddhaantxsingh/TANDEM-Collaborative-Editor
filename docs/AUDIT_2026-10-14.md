# Audit, 2026-10-14

Scope: offline CRDT convergence, multi-node WebSocket sync, persistence,
auth/session revalidation, deployment, load. Every result below comes from
a command run in a shared 4-vCPU container; logs are in
`docs/evidence/2026-10-14/`. Load averages during the runs were 11-42,
so timing numbers are pessimistic and noisy.

## Findings

| ID | Severity | Finding | Status | Evidence |
| --- | --- | --- | --- | --- |
| P10 | High | A client update with missing causal dependencies, arriving while another pending update was already stashed, was acknowledged but not written to PostgreSQL. Yjs merges new pending structs into the existing pending object in place; the server compared object identity. If the dependency later arrived via Redis, the update was never stored: a violation of "ACK means commit". | FIXED (raw update stored whenever anything is pending) | regression P10 in `regressions.test.ts`; `pending-ack-before.log` (fails: "ab" vs "abc"), `pending-ack-after.log`; found by `offline-property.test.ts` (`offline-property.log`) |
| S1 | High | A WebSocket stayed open after its session ended: logout closed sockets only on the node that handled it; expired sessions and sessions deleted in the database kept their sockets. | FIXED: `session-revoked` bus event, per-socket expiry timer, periodic revalidation (`SESSION_REVALIDATE_MS`, 30 s) | `session.test.ts`, `session-revalidation-before.log` (7 of 9 fail), `-after.log` |
| S2 | Medium | Membership removal, role downgrade and document deletion reach other nodes only by Redis pub/sub (at-most-once). A lost message left a removed user able to read and write until reconnect. | FIXED: revalidation re-reads memberships, roles, documents; newer events are not overwritten by an older read | `session.test.ts` "permission revalidation" |
| S3 | Low | Logout closed all of the user's sockets on that node, including other devices with valid sessions. | FIXED: logout closes only its session; new `POST /api/auth/logout-all` | `session.test.ts` |
| R1 | High | A PostgreSQL connection lost while a pool client was checked out (between statements of a transaction) raised an unhandled `error` event and killed the server process. | FIXED: error listener on every pool client | `db-resilience.test.ts`, `pg-client-error-before/after.log`, seen in `crash-ack-mutation.log` |
| T1 | Low | Two security tests depended on test order/timing (shared Redis rate-limit window; startup query race). | FIXED | `flaky-security-before/after.log` |
| T2 | Low | Fragmentation test spent > 60 s in a deep `toEqual` over multi-MB arrays on a busy machine. | FIXED | `final-tests.log` |
| T3 | Info | Raw `Y.encodeStateAsUpdate` bytes are not a canonical form in Yjs. In 200 runs after the fix all raw encodings were equal; the test asserts canonical bytes (re-encode in a fresh doc) and logical equality, and only counts raw equality. | documented | `offline-property.test.ts` |
| D1 | Info | Docker image and compose stack were not built here: the shared disk was 98-100 % full. | OPEN (BLOCKED) | `docs/OWNER_ACTIONS.md` |
| C1 | Info | Resume claim "operational transformation as an alternate merge strategy" is not supported: there is no OT code. | OPEN (owner should correct the resume) | `docs/RESUME_BULLETS.md` |

## Tests added

* `packages/server/test/session.test.ts` (9): logout across nodes, logout scope, log out everywhere, expiry, admin revocation, valid sessions undisturbed, membership/role/document changes without bus events.
* `packages/server/test/offline-property.test.ts`: fast-check, 2-5 clients over 2 nodes, offline periods, duplicate/reorder/delay faults, byte-level checks against both server replicas and PostgreSQL.
* `packages/server/test/db-resilience.test.ts`: killed backend of a checked-out client.
* Regression P10 in `regressions.test.ts`.
* `tools/crash-ack.ts` + `tools/pg-crash-cluster.sh`: kill -9 of the server and of PostgreSQL during writes. CI runs the server mode.
